# 1C BSL AI Copilot (NormaHub)

Бесплатный AI-ассистент для разработчиков платформы **1С:Предприятие 8.3 (BSL)** в редакторах **Cursor**, **VS Code**, **Windsurf** и **VSCodium**.

Работает напрямую через шлюз [NormaHub](https://normahub.cc) без VPN с посекундной тарификацией за реально использованные токены (Pay-As-You-Go) без ежемесячных подписок.

---

## Возможности

### 1. Умный автокомплит BSL на лету (Ghost Text)
* Построчное и блочное дополнение процедур, функций, циклов и условий прямо во время набора текста с задержкой **< 250 мс**.
* Работает на модели `deepseek-v4.1-flash` через прямой сетевой маршрут NormaHub (стоимость: ~0.0018 ₽ за 100 строк сгенерированного кода).
* Корректно расставляет директивы компиляции: `&НаКлиенте`, `&НаСервере`, `&НаСервереБезКонтекста`.

### 2. Конструктор запросов 1С по стандартам ИТС (Query AI Wizard)
* Генерация сложных пакетов запросов 1С по словесному описанию на русском языке (`Ctrl+Alt+Q`).
* Автоматическое соблюдение стандартов разработки фирмы «1С»:
  * Использование параметров в срезах и остатках виртуальных таблиц (`РегистрНакопления.Остатки(&Период, )`).
  * Использование `МенеджерВременныхТаблиц` для исключения неоптимальных прямых соединений с виртуальными таблицами.
  * Оборачивание числовых полей в `ЕСТЬNULL`.
  * Автоматическая генерация блока `Запрос.УстановитьПараметр(...)`.

### 3. Инспектор стандартов разработки фирмы «1С» (ИТС)
* Экспресс-аудит активного модуля или выделенного фрагмента (`Ctrl+Alt+I`):
  * **`ITS-PERF-001`**: Запрос внутри цикла (`Запрос.Выполнить()` в `Для Каждого`).
  * **`ITS-PERF-002`**: Обращение к виртуальным таблицам без фильтрации в параметрах таблицы.
  * **`ITS-LOCK-001`**: Отсутствие объекта `БлокировкаДанных` в процедуре `ОбработкаПроведения`.
  * **`ITS-UI-003`**: Устаревшие модальные вызовы (`Предупреждение`, `Вопрос`).

### 4. Контекст метаданных конфигурации
* Плагин сканирует структуру конфигурации в проекте (`Configuration.xml` или файлы EDT).
* Модель знает точные имена ваших справочников, документов и регистров (например, `Справочник.Номенклатура`, `Документ.ЗаказКлиента.Товары`), что исключает галлюцинации с несуществующими полями.

### 5. Прозрачный баланс в рублях (Pay-As-You-Go)
* В строке состояния редактора отображается текущий остаток: `$(hubot) 1С Copilot: 250.00 ₽`.
* Нет абонентской платы: вы платите только доли копейки за сгенерированный код.
* Пополнение от 100 ₽ через СБП, картами МИР, а для юридических лиц — по безналичному расчету с закрывающими документами по ЭДО Диадок (НДС 20%).

## Установка

### 1. Установка из готового пакета VSIX
```bash
# Для Cursor
cursor --install-extension 1c-bsl-ai-copilot-1.0.0.vsix

# Для VS Code
code --install-extension 1c-bsl-ai-copilot-1.0.0.vsix
```

### 2. Через интерфейс редактора
1. Откройте панель расширений (`Ctrl+Shift+X`).
2. Меню `...` в правом верхнем углу $\to$ **Install from VSIX...**
3. Выберите файл `1c-bsl-ai-copilot-1.0.0.vsix`.

---

## Быстрый старт

1. Получите API-ключ в личном кабинете [NormaHub](https://normahub.cc).
2. В редакторе нажмите на статус-бар `$(hubot) 1С Copilot` или нажмите `F1` $\to$ **1С: Настроить API-ключ NormaHub**.
3. Вставьте ключ (`nr_hub_...`). Он надежно сохранится в системном брелке ОС (`SecretStorage`).
4. Откройте любой файл модуля 1С (`.bsl`, `.os`) и начните писать код.

## Горячие клавиши

| Сочетание | Команда | Описание |
|---|---|---|
| `Ctrl+Alt+Q` | `normahub1c.generateQuery` | Сгенерировать пакет запроса 1С по словесному ТЗ |
| `Ctrl+Alt+I` | `normahub1c.auditStandards` | Проверить выделенный BSL-код на стандарты ИТС |
| `Alt+\` | `editor.action.inlineSuggest.trigger` | Принудительно запросить автодополнение строки |
