# 1C BSL AI Copilot (NormaHub)

Бесплатный AI-ассистент для разработчиков платформы **1С:Предприятие 8.3 (BSL)** в редакторах **Cursor**, **VS Code**, **Windsurf** и **VSCodium**.

Работает напрямую через шлюз [NormaHub](https://normahub.cc) без VPN с посекундной тарификацией за реально использованные токены (Pay-As-You-Go) без ежемесячных подписок.

---

## Возможности

### 1. Умный автокомплит BSL на лету (Ghost Text)
* Построчное и блочное дополнение процедур, функций, циклов и условий прямо во время набора текста с задержкой **< 250 мс**.
* Работает на модели `deepseek-v4.1-flash` через прямой сетевой маршрут NormaHub (стоимость: ~0.0018 ₽ за 100 строк сгенерированного кода).
* Корректно расставляет директивы компиляции: `&НаКлиенте`, `&НаСервере`, `&НаСервереБезКонтекста`.
* Встроенный контекст Библиотеки Стандартных Подсистем (БСП) для генерации кода без создания избыточных объектов в памяти.

### 2. Конструктор пакетов запросов 1С по стандартам ИТС (`Ctrl+Alt+Q`)
* Генерация сложных пакетов запросов 1С по словесному описанию на русском языке или по интерактивному мастеру.
* Автоматическое соблюдение стандартов разработки фирмы «1С»:
  * Выделение исходных выборок во временные таблицы (`ПОМЕСТИТЬ ВТ_...`) с обязательной индексацией (`ИНДЕКСИРОВАТЬ ПО`).
  * Параметризация виртуальных таблиц в скобках (`РегистрНакопления.Остатки(&Период, Номенклатура В (...))`) без прямых соединений.
  * Использование `МенеджерВременныхТаблиц`.
  * Защита от `NULL` через `ЕСТЬNULL(..., 0)`.
  * Автоматическая очистка оперативной памяти сервера в конце пакета (`УНИЧТОЖИТЬ ВТ_...`).

### 3. Генератор расширений конфигурации (`cfe`) (`Ctrl+Alt+E`)
* Разработка доработок для типовых конфигураций (1С:ERP, КА, УТ, ЗУП, БП) **без снятия с поддержки**:
  * **`&Вместо`**: генерация перехвата с безопасным вызовом `ПродолжитьВызов(...)`.
  * **`&Перед`**: валидация входных данных и контроль флага `Отказ`.
  * **`&После`**: постобработка результатов и запись в дополнительные регистры.
  * **`&ИзменениеИКонтроль`**: промышленный патчинг с тегами `#Вставка` и `#КонецВставки`.
  * Генерация динамических кнопок и команд формы в `ПриСозданииНаСервере`.

### 4. Ассистент Библиотеки Стандартных Подсистем (БСП) (`Ctrl+Alt+B`)
* Каталог проверенных методов типовых модулей БСП:
  * `ОбщегоНазначения.ЗначениеРеквизитаОбъекта(...)` вместо тяжелого `ПолучитьОбъект()`.
  * `СтроковыеФункцииКлиентСервер.РазложитьСтрокуВМассивПодстрок(...)`.
  * `ДлительныеОперации.ЗапуститьВыполнениеВФоне(...)` для неблокирующего интерфейса.
  * `Пользователи.АвторизованныйПользователь()`.

### 5. Инспектор стандартов разработки фирмы «1С» (ИТС) (`Ctrl+Alt+I`)
* Экспресс-аудит активного модуля или выделенного фрагмента:
  * **`ITS-PERF-001`**: Запрос внутри цикла (`Запрос.Выполнить()` в `Для Каждого`).
  * **`ITS-PERF-002`**: Обращение к виртуальным таблицам без фильтрации в параметрах таблицы.
  * **`ITS-LOCK-001`**: Отсутствие объекта `БлокировкаДанных` в процедуре `ОбработкаПроведения`.
  * **`ITS-UI-003`**: Устаревшие модальные вызовы (`Предупреждение`, `Вопрос`).
  * **`ITS-MUTABLE-001`**: Передача мутабельных объектов (`ТаблицаЗначений`) между клиентом и сервером.
  * **`ITS-QUERY-001`**: Прямое соединение с виртуальной таблицей в запросе.
  * **`ITS-BSP-001`**: Замена ручного кода на стандартные методы БСП.

### 6. Контекст метаданных конфигурации
* Плагин сканирует структуру конфигурации в проекте (`Configuration.xml` или файлы EDT).
* Модель знает точные имена ваших справочников, документов, регистров и табличных частей, исключая галлюцинации с несуществующими полями.

### 7. Прозрачный баланс в рублях (Pay-As-You-Go)
* В строке состояния редактора отображается текущий остаток: `$(hubot) 1С Copilot: 250.00 ₽`.
* Нет абонентской платы: вы платите только доли копейки за сгенерированный код.
* Пополнение от 100 ₽ через СБП, картами МИР, а для юридических лиц — по безналичному расчету с закрывающими документами по ЭДО Диадок (НДС 20%).

## Горячие клавиши

| Сочетание | Команда | Описание |
|---|---|---|
| `Ctrl+Alt+Q` | `normahub1c.generateQuery` | Сгенерировать пакет запроса 1С по словесному ТЗ |
| `Ctrl+Alt+E` | `normahub1c.generateExtensionMethod` | Создать перехват для расширения (&Вместо / &ИзменениеИКонтроль) |
| `Ctrl+Alt+B` | `normahub1c.bspAssistant` | Вставить вызов метода БСП (ОбщегоНазначения, ДлительныеОперации) |
| `Ctrl+Alt+I` | `normahub1c.auditStandards` | Проверить выделенный BSL-код на стандарты ИТС и БСП |
| `Alt+\` | `editor.action.inlineSuggest.trigger` | Принудительно запросить автодополнение строки |

## Установка

### 1. Установка из готового пакета VSIX
```bash
# Для Cursor
cursor --install-extension 1c-bsl-ai-copilot-1.0.0.vsix

# Для VS Code
code --install-extension 1c-bsl-ai-copilot-1.0.0.vsix
```

### 2. Через интерфейс редактора
1. Откройте панель расширений (`Ctrl+Shift+X`).
2. Меню `...` в правом верхнем углу $\to$ **Install from VSIX...**
3. Выберите файл `1c-bsl-ai-copilot-1.0.0.vsix`.
