# Внешняя обработка NormaHub AI Copilot для 1С:Предприятие 8.3 (`.epf`)

Нативная обработка для управляемого и толстого клиента 1С:Предприятие 8.3 (любой конфигурации: ERP 2.5, УТ 11, КА 2, БП 3.0, ЗУП 3.1, УНФ).

---

## 1. Назначение и возможности

1. **Выгрузка 100% метаданных конфигурации в один клик**:
   - Обходит `Метаданные.Справочники`, `Метаданные.Документы`, `Метаданные.РегистрыНакопления`, `Метаданные.РегистрыСведений`, `Метаданные.ПланыВидовХарактеристик`.
   - Извлекает реквизиты, типы, синонимы, табличные части, измерения и ресурсы.
   - Сохраняет файл `metadata.json`, который мгновенно подхватывается плагином VS Code и LLM-шлюзом NormaHub для генерации строго типизированных запросов и кода.

2. **Интерактивный ИТС-аудит качества кода прямо в 1С**:
   - Вставьте любой метод BSL в поле ввода.
   - Получите моментальный отчет с индикаторами критичности (🔴 Критично, 🟡 Предупреждение) и готовыми подсказками по устранению замечаний стандартов фирмы «1С».

3. **Генератор пакетных запросов по стандартам ИТС**:
   - Укажите имя документа, табличной части и регистра накопления.
   - Обработка сгенерирует оптимизированный пакет с временными таблицами (`ПОМЕСТИТЬ ВТ_`), индексами (`ИНДЕКСИРОВАТЬ ПО`), конструкцией `ЕСТЬNULL` и правильной очисткой (`УНИЧТОЖИТЬ ВТ_`).

4. **Генератор BDD-сценариев Vanessa-Automation**:
   - Генерация нативных сценариев на русском языке Gherkin для сквозного тестирования документов.

5. **Диагностика Технологического Журнала (ТЖ)**:
   - Вставка фрагментов ТЖ с расшифровкой таймаутов `TLOCK`, взаимоблокировок `TDEADLOCK`, исключений `EXCP` и неоптимальных запросов `DBPOSTGR`/`DBMSSQL`.

---

## 2. Как использовать

1. Убедитесь, что запущен локальный фоновый сервис (Sidecar):
   ```bash
   python3 -m sidecar.main
   ```
   (Сервис слушает порт `18833` на `127.0.0.1`).
2. В режиме «1С:Предприятие» откройте внешнюю обработку через меню **Файл $\to$ Открыть...** (или зарегистрируйте её в справочнике «Дополнительные отчеты и обработки» БСП).
3. Нажмите кнопку **«Выгрузить метаданные»** и сохраните `metadata.json` в корень рабочего каталога вашего проекта в VS Code.

---

## 3. Файловая структура исходников обработки

- `NormaHubCopilot_Module.bsl` — программный модуль объекта (обход метаданных, HTTP-клиент к Sidecar).
- `NormaHubCopilot_Form.bsl` — модуль управляемой формы (обработчики команд интерфейса).
