## Порог решения

Сейчас допустим **внутренний preview 1.0.12** и подготовка открытой беты. Публичный анонс, платное продвижение и обещания «готово для всех 1С» не подтверждены: в этой версии не запущен свежий live NormaHub корпус и не проверена доставка из реестров. После live и post-install решение надо принять по фактической доле применимых ответов и стоимости полезного результата, а не по одному коду выхода тестов.
