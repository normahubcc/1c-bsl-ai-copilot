# Бриф для CEO и копирайтера: ограниченная бета

Статус на 2026-11-02: **локальный VSIX 1.0.11 готов для ограниченной беты; массовый production-релиз пока NO-GO**. Пакет не опубликован и worktree не закоммичен. Этот бриф разрешает готовить текст, но сам по себе не означает открытый набор участников или доступность новой версии в каталогах.

## Что можно утверждать

| Формулировка | Основание |

| Есть локальные проверки и шаблоны, работающие без AI-ключа | Core/MCP/Sidecar regression и packaged MCP smoke; результат является рекомендацией или черновиком |

| Панель имеет русский и английский интерфейс | RU/EN host/Webview regression и packaged языковые каталоги |

## Чего пока нельзя обещать

- «Полностью готов для промышленной эксплуатации 1С/B2B», «проверяет весь BSL-код», «автоматически утверждает бизнес-корректность».
- Гарантированное ускорение разработчика, фиксированные p95 или мгновенное автодополнение. Предыдущий live inline N=5 имел медиану API 6,183 с и p95 6,758 с; выборка мала.
- Качество DeepSeek 1017 на всех сценариях: 13 сценариев запросов из общего frozen корпуса в 30 задач ещё не запускались, gateway не предоставил независимую аттестацию точного upstream build.
- Готовые `.cfe`/`.epf`, подтверждённая работа Vanessa, TurboConf, ERP/УПП и разных релизов конфигураций без отдельных реальных проверок.
- Доступность 1.0.11 в VS Code Marketplace/Open VSX до фактической публикации и проверки карточки.

## Текстовая основа для новости о бете

**Заголовок:** «1C BSL AI Copilot: готовим ограниченную бету расширения для VS Code и Cursor».

**Лид:** «Расширение помогает разработчику 1С работать с BSL: предлагает автодополнение, готовит черновики запросов и объяснения кода, показывает результат перед применением и содержит локальные инструменты проверки. AI-функции используют NormaHub API; локальные шаблоны доступны без ключа. Мы приглашаем команду бета-пользователей проверять полезность на своих сценариях и сообщать о неудачных результатах».

**Уточнение в материале:** «Ответ AI остаётся черновиком. Проверка выбранного запроса в 1С доступна в отдельном операторском стенде; она не подтверждает выполнение полного модуля или соответствие бизнес-требованию».

Перед публикацией владелец запуска должен указать реальный канал набора/поддержки, ссылку на опубликованную версию или на выдаваемый бета-VSIX, актуальные условия оплаты NormaHub и инструкцию по обратной связи. Копирайтеру не следует придумывать эти данные.
