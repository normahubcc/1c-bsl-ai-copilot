# 1C BSL AI Copilot 1.0.12 — открытая бета

Расширение для разработки BSL в VS Code и Cursor. AI готовит черновики запросов и объяснений; результат показывается перед применением к исходному документу. Локальные проверки, шаблоны и девять MCP-инструментов доступны без NormaHub API-ключа.

## Что изменилось

- Сохранена защита исходного документа при preview/apply и отмена устаревших AI-запросов. После принятого Tab повторный автоматический вызов для неизменённого документа подавляется.
- Обновлена сборка на `esbuild 0.28.2`; текущий `npm audit` не обнаружил известных уязвимостей в зависимостях.
- README внутри VSIX теперь прямо указывает beta-статус, передачу контекста в NormaHub и неподтверждённые редакторы. Публикация проходит через проверенный GitHub draft и точный пакет с `SHA256SUMS`.

## Установка и первый сценарий

Установите расширение из [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=Normahub.1c-bsl-ai-copilot) или [Open VSX](https://open-vsx.org/extension/normahub/1c-bsl-ai-copilot). Убедитесь, что карточка предлагает именно **1.0.12**. Для ручной установки скачайте VSIX из вложений этого релиза и сверьте его с `SHA256SUMS`. Откройте собственный `.bsl` в VS Code/Cursor, запустите локальную проверку без ключа, затем при необходимости подключите ключ NormaHub и получите AI-черновик запроса. Просмотрите preview, проверьте имена метаданных и результат в своей тестовой 1С, затем примените код.

## Границы беты

- AI-ответ — черновик, не подтверждение бизнес-корректности. Эвристический аудит не заменяет BSL Language Server, Конфигуратор или выполнение в 1С.
- Облачные задачи отправляют ограниченный фрагмент кода и контекста в NormaHub; стоимость зависит от модели и фактического использования. Локальные инструменты не требуют ключа.
- Inline-подсказки могут приходить медленно. Мы не обещаем фиксированную задержку; предыдущая малая live-выборка показала медиану API 6,183 с на пяти вызовах.
- Проверены VS Code/Cursor и выбранные SELECT в собственной учебной Linux 1С. Работа Windsurf/VSCodium, произвольных ERP/УПП, готовых `.cfe`/`.epf`, Vanessa и TurboConf не подтверждена тем же набором испытаний.

Если нашли ошибку, откройте [GitHub Issue](https://github.com/normahubcc/1c-bsl-ai-copilot/issues/new/choose) с версией IDE/расширения и обезличенным минимальным примером. Не публикуйте API-ключи, клиентский код, личные данные и сырые технологические журналы.
