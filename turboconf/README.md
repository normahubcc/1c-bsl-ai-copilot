# Интеграция NormaHub AI Copilot с TurboConf для 1С:Конфигуратора

Скрипт интеграции позволяет использовать возможности AI Copilot прямо в стандартном окне редактора модулей 1С:Конфигуратора под Windows без переключения в сторонние программы.

---

## 1. Возможности

- **Горячая клавиша `Ctrl+Alt+Space`** — Дописать код (AI Autocomplete): берет текущий контекст метода и генерирует продолжение BSL-кода в позицию курсора.
- **Горячая клавиша `Ctrl+Alt+I`** — Мгновенный ИТС-аудит качества кода: проверка выделенного фрагмента на соответствие стандартам фирмы «1С» с выводом всплывающих уведомлений.
- **Горячая клавиша `Ctrl+Alt+Q`** — Вставка промышленного шаблона пакетного запроса с временными таблицами и управляемыми блокировками.

---

## 2. Установка в TurboConf

1. Убедитесь, что у вас установлен [TurboConf](https://turboconf.ru/) для 1С:Предприятия.
2. Скопируйте файл `normahub_copilot.os` в каталог пользовательских скриптов TurboConf:
   ```text
   %APPDATA%\TurboConf\Scripts\normahub_copilot.os
   ```
   (или в настроенную папку внешних скриптов в настройках TurboConf).
3. Перезапустите TurboConf или нажмите **Обновить скрипты** в меню программы.
4. Убедитесь, что запущен локальный сервис NormaHub Sidecar:
   ```bash
   python -m sidecar.main
   ```
5. В Конфигураторе 1С откройте любой модуль и нажмите `Ctrl+Alt+Space` для проверки работы.
