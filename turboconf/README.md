# Экспериментальный адаптер TurboConf

`normahub_copilot.os` — исходник адаптера для ручной установки и проверки. API объекта `ТурбоКонф` и его поведение требуют проверки в установленной версии TurboConf. Автоматические тесты расширения не подтверждают работу этого скрипта внутри Конфигуратора.

1. Установите OneScript и TurboConf, проверьте совместимость используемых методов `ТурбоКонф` с вашей версией.
2. Запустите Sidecar: `python3 sidecar/main.py daemon`. Нужны Node.js и включённое ядро `dist/toolbox-cli.js`.
3. Скопируйте скрипт в настроенный каталог пользовательских скриптов TurboConf и перезагрузите их.
4. Для защищённого Sidecar задайте тот же `SIDECAR_AUTH_TOKEN` в окружении процесса, запускающего скрипт. Токен передаётся заголовком; в файле его не храните.
5. Проверьте команды на отдельном тестовом модуле.

`Ctrl+Alt+Space` отправляет выделенный текст (либо весь модуль) на `/v1/complete` и вставляет ответ через API TurboConf. Это отдельный экспериментальный путь; он пока не имеет защиты preview/version, которую предоставляет VS Code-расширение. Для обычной работы используйте основной редактор с предпросмотром.

`Ctrl+Alt+I` запрашивает локальные замечания через `/v1/audit`. Шаблон с фиксированной конфигурацией удалён; параметризованные запросы доступны в панели расширения или через Sidecar REST с явными именами и полями.
