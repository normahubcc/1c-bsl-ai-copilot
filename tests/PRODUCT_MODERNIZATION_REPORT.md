## Реализованный результат

| Область | Итоговое поведение |
|---|---|
| Команды, панель, shortcuts | Один workflow на задачу. Command Palette открывает тот же инструмент; отдельные обработчики с прямой вставкой/заменой файла удалены. Контекстные меню и клавиши ограничены BSL/1c/oscript. Дублирующая форма генерации запроса объединена с основной рабочей областью. |
| Preview и применение | Host хранит код по preview ID. Цель фиксируется до асинхронного запроса: URI, версия и позиция. Изменённый документ блокирует применение; смена активного файла не меняет цель. Одновременные клики и повторное применение одного preview блокируются. Произвольный raw code из Webview не применяется. Результат можно открыть отдельно или скопировать. |
| Генерация запросов | Общий AI service с реальным контекстом исходного редактора, метаданными и сигнатурами соседних модулей. Выделение/код захватываются до ожиданий. Есть отмена, блокировка дублирующих запросов, распаковка единственного code fence, отказ при пустом, нетекстовом и обрезанном лимитом ответе. Результат обозначен как черновик. |
| Batch | BSL-строка сохраняет точный текст запроса с переводами строк. Имена валидируются, все измерения явно задаются пользователем и сохраняются в проекциях/соединении; один числовой ресурс задаётся последним. Поддержка ограничена контролем дефицита через Остатки регистра накопления. UI не обещает готовое проведение с движениями/блокировками. |
| Локальное преобразование запроса | Сохраняет проекции, имена ресурсов, параметры виртуальной таблицы и NULL-семантику. Не подставляет Количество в запрос цен. Поддерживает один SELECT с одним виртуальным JOIN; неподдерживаемый вход возвращает без изменений с reason. Смена индекса результата пакета явно объясняется. Plain query открывается отдельно и не вставляется автоматически в BSL-модуль. |
| Расширения и форма | Поддержаны процедуры, функции с возвратом результата, известные сигнатуры событий и параметры Знач. Идентификаторы проверяются; кавычки/переносы заголовка экранируются. Функции поддерживаются через Вместо. ИзменениеИКонтроль без исходника отклоняется. Это BSL-шаблоны, не готовый .cfe. |
| ИТС и БСП | Снята сертифицирующая формулировка полного соответствия. Комментарии не вызывают query/BSP-замечания. Отсутствие явно найденной блокировки — предупреждение с ограничением эвристики. Заявление о нереализованной mutable-проверке удалено. Статические примеры БСП не навязываются модели как подтверждённые API проекта. AI-объяснение доступно рядом с проверками. |
| BDD | Локальный каркас сохраняет полное требование и указанные объекты; выдуманные пользователи, товары, числа и шаги убраны. Отдельный явный AI-режим учитывает полное требование, документ, табличную часть, регистр и контекст. Результат требует сверки со своей Vanessa-библиотекой. |
| ТЖ | Нераспознанный ввод отличается от успешно разобранного лога без совпадений. SQL менее секунды не объявляется медленным. Уточнены пороги, обработка кавычек/запятых и формулировки рекомендаций. |
| Метаданные | Нет синтетической fallback-схемы. Реализован валидируемый metadata.json (до 8 МБ), повторный scan очищает кэши. XML/EDT-поля табличных частей отделяются от реквизитов объекта. Контекст выбирается по активному проекту; неоднозначный unsaved/multi-root не заимствует чужую схему и соседние модули. Обновление индикатора исправлено и проверено браузером. |
| Подключение и модели | Генерация и ghost text имеют отдельные настройки. Выбор reasoning-модели не перезаписывает autocompleteModel. Есть удаление сохранённого ключа и переход в настройки расширения. Пустой ввод не удаляет ключ. Баланс управляется внешним кабинетом; неподтверждённые цена/промобонус убраны. |
| Inline | Сохранён предыдущий lifecycle/context/normalizer/metrics hardening и пользовательские бюджеты. Добавлены untitled:1c/oscript, учёт metadata.json в инвалидации и изоляция контекста между проектами. |
| Sidecar и MCP | Один TypeScript core для локальных инструментов вместо расходящихся Python-копий. Python вызывает упакованный toolbox-cli через pipes без shell. Валидация JSON/параметров, HTTP 400/413/403/401 и корректное распознавание health. HTTP 401, чужой сервис, malformed JSON и timeout не означают подключение. |
| Интеграции | MCP/Sidecar перенесены из главного каталога в дополнительную настройку. Документация открывается из установленного расширения. Исправлены HTTP/TLS-несоответствие и передача Sidecar bearer token в адаптерах. EPF описан как ручная сборка исходников; TurboConf — как экспериментальный путь. Фиксированный запрос чужой конфигурации удалён. |
| Архитектура и документация | Новая логика разделена между shared, entities/toolbox и features (AI, применение preview, интеграции). Runtime browser mock transport и активные демо-результаты удалены. README, changelog, manifest, упаковка и release QA обновлены. |

## Остаточные release gates

Кандидат годится для следующего этапа beta-проверки. Массовая production-готовность пока не подтверждена:

1. Ручной Tab/undo/cancellation/offline smoke в настоящем Extension Host VS Code и Cursor.
2. Live NormaHub p50/p95/p99 и качество ответа на реальных задачах; доступность моделей и тарификация зависят от шлюза.
3. Выполнение сгенерированного BSL/пакетов на тестовой конфигурации, включая типы, измерения, блокировки, транзакции и движения вызывающего кода.
4. Запуск .feature с конкретной библиотекой Vanessa и реальными тестовыми данными.
5. Проверка исходников EPF/TurboConf на конкретной версии платформы/адаптера. У экспериментального TurboConf-пути пока нет защиты preview/version основного расширения.

Числовая гарантия задержки, полное соответствие ИТС и гарантированное ускорение запросов не заявляются. Прежний отчёт автодополнения оставлен как исторический документ; эта запись описывает текущий локальный кандидат.
