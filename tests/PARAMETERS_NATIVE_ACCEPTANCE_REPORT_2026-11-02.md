## Изменение контракта и продукта

Протокол v2 принимает до 32 явно заданных scalar параметров; имена и типы проверяются, значения фиксируются в challenge/request/worker observation/signed receipt, неизвестные или неиспользуемые значения отвергаются. Строки никогда не вставляются в текст SELECT. `Дата` и `Ссылка` остаются доверенными значениями фикстуры. Исторические v1 receipts продолжают проверяться; новые v1 задания с дополнительными параметрами получают понятный отказ до запуска. Мастер показывает типы и значения на RU/EN и спрашивает независимый ожидаемый результат.

Клиент NormaHub теперь распознаёт обрезанный ответ, отдельно показывает случай, когда большую часть лимита заняло рассуждение, и передаёт в диагностике только числовые счётчики и фиксированный статус. Код, prompts и ключи в эту диагностику не попадают. Модель остаётся `deepseek-v4.1-flash-1017`; ответ API по-прежнему не доказывает upstream build, если gateway возвращает каноническое имя семейства.
