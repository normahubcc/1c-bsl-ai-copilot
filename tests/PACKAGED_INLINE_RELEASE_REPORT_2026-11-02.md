# Проверка установленного VSIX и стоимости автодополнения, 2026-11-02

**Результат:** локальный кандидат 1.0.11 прошёл физическое принятие подсказок в установленном VSIX в VS Code 1.141.0 и Cursor 1.105.1. При штатном debounce 250 мс контрольный транспорт получил один запрос для подсказки и ни одного повторного запроса в течение 700 мс после Tab/Escape. Это закрывает локальный пробел packaged IDE, но не подтверждает live задержку/стоимость NormaHub или качество модели на будущих задачах.

## Почему потребовалось изменение

Предыдущая проверка Tab использовала актуальный исходный provider, а установленный VSIX 1.0.10 проверялся отдельно на активацию/команды. После подключения контролируемого HTTPS к **самому установленному** пакету обнаружилось: при принятии каждой из четырёх подсказок VS Code и Cursor автоматически отправляли второй запрос на неизменённом тексте. Это воспроизвелось как при ускоренном debounce 0 мс, так и при штатных 250 мс. Для токеновой тарификации повторный запрос может создать лишний расход; фактическое списание не измерялось, поскольку transport в тесте контролируемый.

В 1.0.11 `InlineCompletionItem.command` сообщает provider о принятии уже вставленной подсказки. Автоматический запрос для той же версии документа пропускается; новая печать или явный вызов пользователем разрешают следующий запрос. Команда не несёт кода, prompts или ключа. Unit lifecycle проверил оба разрешённых перехода; физический Tab в установленном пакете подтвердил отсутствие повторного вызова.

| Проверка, одинаково в обеих IDE | VSIX 1.0.10 | VSIX 1.0.11 |
| --- | ---: | ---: |
| Точная вставка сохранённых реальных ответов 1017 i01–i04 через физический Tab | 4/4 | 4/4 |
| Отклонение i05 (`КонецДня(Дата)`) через Escape без правки исходника | 1/1 | 1/1 |
| Контролируемых HTTPS-вызовов до каждого действия | 1 | 1 |
| Дополнительных вызовов в 700 мс после каждого Tab | 1 | 0 |
| Дополнительных вызовов после Escape | 0 | 0 |

Тест запускал пакет в новом профиле на отдельном Xvfb. Он сверял SHA установленного `dist/extension.js` с точным VSIX, подставлял **только синтетический ключ в памяти extension host** и перехватывал HTTPS NormaHub до сети. Контент ответа брался из сохранённого live-прогона 2026-10-31; исходный provider не импортировался. Драйвер отправлял физический Tab/Escape только при видимом ghost text и сравнивал весь буфер с ожидаемым текстом. Подмена без ghost text не засчитывалась.
